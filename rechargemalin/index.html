Questions fréquentes

D'où viennent les données ?
De la Base nationale des infrastructures de recharge (IRVE), publiée chaque jour sur data.gouv.fr sous Licence Ouverte. Les informations sont déclarées par les opérateurs de bornes.

Une borne est fausse ou manquante.
Nous affichons les données officielles telles quelles. Les corrections doivent être faites par l'opérateur de la borne auprès de data.gouv.fr ; tu peux aussi nous la signaler.

Pourquoi le tarif est « non communiqué » ?
Beaucoup d'opérateurs ne publient pas de prix dans la base nationale, ou dépendent du badge ou de l'application utilisés. Vérifie toujours le tarif sur la borne avant de charger.

Savez-vous si une borne est libre ?
Non, la disponibilité en temps réel n'est pas publiée dans la base nationale.

Pourquoi le rayon est réduit à Paris ?
Dans les zones très denses, l'application limite automatiquement le rayon pour rester rapide. Utilise les filtres (puissance, prise) pour voir plus loin.
